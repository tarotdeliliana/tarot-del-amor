# Tarot del Amor · de Liliana

## Publicación

El sitio está preparado para Vercel como sitio estático.

- Rama: `main`
- Entrada: `index.html`
- Página principal: `tarot-4-paginas-final.html`
- Configuración: `vercel.json`

## Importación en Vercel

En Vercel: Add New → Project → Import Git Repository → seleccionar `tarotdeliliana/tarot-del-amor` → Deploy.

No cambiar el framework: el proyecto es HTML/CSS/JS estático.
