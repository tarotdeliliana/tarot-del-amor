# Tarot del Amor de Liliana — v0.5

Esta versión conecta el flujo con una base SQLite local y deja lista la arquitectura para producción.

## Incluye
- Web de cliente
- Servicios y formulario
- Creación persistente de usuarios y lecturas
- Tirada Relación 13 cartas
- Cruz Celta 10 cartas
- Panel de Liliana conectado a la base
- Interpretación y estado `ready`
- Registro de eventos para correo
- Registro de pagos pendientes

## Producción
La interfaz está preparada para desplegarse en Vercel y la API está preparada para la función de Supabase.

Online: Rider-Waite-Smith. En vivo: Lover's Path físico de Liliana.
